# P33-03 — Public hub and session presentation

Accepted 25 September 2026. Published and archived festival hubs now have a stable signed-out visitor route at `/events/[slug]`. Festival mode remains Off, no production hub was created or published, and no production data was mutated.

## Acceptance

- Added responsive public presentation for optional organiser branding, long hub/collection/session names, artist/tradition/general collection browsing, programme sessions, archive context, and an empty-hub fallback.
- Reused `/public-lists/[id]` for the canonical tune list, permitted learning references, bookmark/save behaviour, and playback lifecycle. The hub renders no media player and creates no copied repertoire.
- Linked to the normal `/compare` experience with contextual session-bar copy. No automatic comparison, invitation, or festival-specific Compare state was added.
- Public loading remains restricted to Published/Archived hubs and existing public lists. Draft/unknown slugs use the normal not-found route; hidden list associations disappear through the public inner join.
- Excluded curator/profile UUIDs, review flags, and session source notes from public selects/results. Sessions still marked `needs_review` are withheld entirely.
- Added explicit programme-snapshot, timezone, change/cancellation, unknown date/time, suggested-repertoire, and not-proof-of-performance wording. Missing branding, programme link, descriptions, credits, dates, times, venues, and collections render without invented details.
