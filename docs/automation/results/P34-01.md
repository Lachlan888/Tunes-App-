# P34-01 — Today-first Focused Practice

Status: passed on 2026-09-25.

## Acceptance

- `/review` now enters the Focused Practice journey on desktop and mobile. It resumes a same-day account-scoped active session when one exists; otherwise it opens the strict `due-today` lane.
- The existing review loader remains authoritative: `due-today` uses an exact date filter and catch-up uses the existing overdue filter/order. The initial queue does not mix overdue tunes.
- Completing today's queue, including starting with zero due tunes, renders the completion state. Catch-up is offered only through the explicit `Continue with catch-up` action when overdue work exists.
- Refreshing an explicit session preserves the existing date/lane storage key, queue position and safe display history. Primary Practice navigation can also recover the validated active lane; stale, malformed and incomplete scoped-session markers are rejected.
- Existing rating, Stage, review persistence, note and learning-queue behaviour is unchanged.

## Changed hunks

- `app/review/page.tsx`: routes the bare Practice destination through the focused entry resolver and supplies the overdue count to a live session.
- `components/practice/PracticeEntryResolver.tsx`: resolves a validated active session or today's queue without rendering the old dashboard.
- `components/practice/FocusedPracticeSession.tsx`: records/clears active-session identity and adds the zero-due/today-complete state with optional catch-up continuation.
- `lib/practice-session.ts`: validates same-day resumable session markers.
- `tests/practice-session.test.ts`, `tests/review-bounds.test.ts`: cover resume validation, direct entry, completion/catch-up wiring and strict lane membership.
