## Implementation

- Removed the broad V01 global selectors that flattened arbitrary wrappers and controls. Editorial structure now remains the responsibility of route components and shared primitives rather than a CSS disguise.
- Reworked desktop navigation current state to a single thin action-colour rule, kept hover visually quieter and distinct, removed native title popovers, and added compact-rail labels that can appear on hover or keyboard focus.
- Integrated the mobile header and six-destination dock into the canvas instead of treating them as floating cards; safe-area padding, focus rings and minimum touch targets remain.
- Added route-aware `aria-current` and restrained left-rule selection to account-menu destinations, including Practice tools and role-gated entries. The menu heading and Social grouping now follow the agreed title-case sans hierarchy.
- Preserved all route destinations, badges, gates, event-driven actions and existing data flows. Existing dirty V01/P35 work was reconciled rather than reset.
