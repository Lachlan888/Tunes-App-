# P29-a — Bounded friend suggestions

Accepted 24 September 2026.

Implemented a deterministic, visibility-first suggestion loader in `lib/loaders/friend-suggestions.ts`. Candidate discovery is capped at 60 profiles and requires the existing compare-discoverability flag before any identity or repertoire signal is read. The loader excludes self and every existing connection row, covering accepted, pending and any blocked relationship state represented there. Display names are fetched separately only for profiles that permit identity display. Repertoire contributes only for candidates who allow non-friend comparison; returned reasons contain aggregate counts or a shared style, never tune identities.

Scoring is fixed and documented in code: 100 points per mutual connection, 20 per shared style (maximum three), and 8 per shared tune (maximum five), followed by stable label and ID ordering. Results are capped at six. Candidate, graph and repertoire reads have fixed row ceilings and no per-suggestion query loop. When no permitted signal exists, the loader returns `insufficient_signals` rather than weak or invented recommendations.
