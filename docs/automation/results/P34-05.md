# P34-05 — Compact mobile tune actions

Passed on 2026-09-25.

## Acceptance

- Mobile catalogue rows now keep the linked title, key and time signature on one bounded line. Long titles truncate with their full title retained as link text/title, and the repertoire state sits directly beneath.
- Mobile actions use one contained four-column row: Preview, Add, Practice and Known. Each control retains a 44px touch target and a full tune-specific accessible name.
- New tunes retain the existing Start Practice and Mark Known server actions, including pending/busy states. Practising and known tunes show the same two actions disabled on mobile with state-specific accessible names rather than exposing invalid mutations.
- Selection mode continues to replace per-row actions with a 44px checkbox target, and its two-column wrapper now explicitly contains long tune identities.
- Desktop retains the existing detailed identity, metadata, action labels, wrapping and spacing through `md:` presentation. Manual responsive/visual acceptance remains user-owned and was not performed.
