# P18-04 — Accessibility and semantic consistency

Accepted 26 September 2026. The focused source audit found no remaining `role="link"`/clickable generic card wrappers in application TSX, and the shared shell retains skip targets, landmarks, visible focus styling, reduced-motion/transparency fallbacks, increased-contrast/forced-colour handling and 44px navigation controls.

## Demonstrated defects and fixes

- Reference Mode's loop-bank load, boundary adjustment and step controls explicitly rendered below 44px. They now expose 44px minimum targets, while the overlapping range controls use a 44px interaction height.
- The loop-pedal and loop-range containers carried accessible names on generic `div` elements without roles. They now expose named groups; the transport play/pause control also reports its pressed state.
- Setlist readiness, known-tune status and the Session Dock showcase similarly labelled generic containers. They now expose `group` or `status` semantics as appropriate.
- The account menu still displayed legacy title-case `Focus Areas`; visible navigation now uses the source-of-truth `Focus areas` name.

Regression assertions were written and observed failing before the implementation changes.

## Scope and limitations

Automated checks cover semantic roles/names, source-of-truth copy, target sizing, shared focus/skip/landmark foundations, accessibility preferences and token contrast. No browser walkthrough, screenshot matrix, deployment, publication, message, commit, festival-mode or production-hub change occurred.
