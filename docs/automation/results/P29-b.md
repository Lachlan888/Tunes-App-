# P29-b — Suggestion UI and action states

Accepted 24 September 2026.

Integrated the P29-a loader into the existing Friends page without changing normal search. Suggestions load only when the search query is empty and run in parallel with friend activity. Up to six musicians appear under Find friends with the privacy-safe display label, one aggregate reason and the existing `sendFriendRequest` server action. Sending from a suggestion returns to `/friends`, where the new pending connection is excluded by the same relationship-state gate; accepted and blocked relationship rows are excluded as well. Displaying suggestions never creates a request.

When no permitted mutual-connection, shared-style or tune-overlap signal exists, the page shows an honest low-data message and keeps name/username search available. The UI does not expose tune identities or hidden display names. Existing duplicate-request, self-request and missing-profile protections remain authoritative in the server action.
