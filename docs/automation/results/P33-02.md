# P33-02 — Dev editing and preview

Accepted 25 September 2026. The owner-only Dev area now provides compact festival creation, editing, preview, launch settings, and existing-public-list association management. Festival mode remains Off, no production hub was created or published, and no production data was mutated.

## Acceptance

- Added a discoverable Festival hubs entry in Dev plus a private owner preview that works while a hub is Draft.
- Added validated create/edit fields for reusable metadata, stable slug, timezone, description, optional paired branding, programme snapshot details, curator credit, lifecycle, and editorial order. New records are still forced to Draft by the server action.
- Added persisted festival mode and selected-hub controls with explicit copy separating Home promotion from publication. The action returns a useful error when mode-on lacks an eligible published selection.
- Added attach, edit/reorder, and detach controls for existing public Lists. Association edits target only `festival_collections`; the normal List editor remains the sole tune-membership path.
- Preserved the Dev route guard, explicit owner-only loader/action checks, and database RLS from P33-01. Automated coverage exercises a denied non-owner server write rather than relying on hidden UI.
