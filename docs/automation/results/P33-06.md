# P33-06 — Home promotion and archive lifecycle

Accepted 25 September 2026.

## Outcome

- Home now loads a modest festival promotion alongside the existing homepage data and renders it only when the fail-closed loader returns a selected published festival.
- The promotion supports optional supplied branding with a text fallback and links to the festival's stable `/events/<slug>` address. Existing Home summary, onboarding content and navigation remain unchanged.
- Promotion reads expose only public hub fields. Mode Off, missing selection, configuration failure, Draft, Archived and missing selected records all omit the Home promotion.
- Settings and lifecycle writes already invalidate Home. Published and Archived hubs remain available at their own stable public address, while returning a hub to Draft withdraws that route.
- No festival mode, selection, lifecycle, saved list or production content was mutated during this slice.
