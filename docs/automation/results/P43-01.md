No auth/data mutation was tested. Catalogue relationship mutations still invoke the existing `markAsKnown`, `startLearning` and `removeFromPractice` server actions. Reference removal requires `createdBy === currentUserId` in the UI, `.eq("created_by", user.id)` in the server action, and the existing `Users can delete their own piece media links` RLS policy in `20260607020000_extend_piece_media_links_for_additional_media.sql`. The UI does not grant a new role.
